# Project rules

These instructions apply throughout this repository.

- Follow the existing Laravel and React conventions in the surrounding code.
- Keep changes focused on the requested task and preserve unrelated work.
- After changing scheduling logic, run the relevant tests before finishing.
- Report any failed tests before finishing, explain the failures, and state any checks that could not be run.
- Include newly added files and their full contents in the Codex Diff, alongside changes to existing files. Check for untracked files before finishing; a tracked-files-only diff is not sufficient. If the diff interface cannot display a new file, show its full contents in the response and explain the limitation.
